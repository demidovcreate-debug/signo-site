Réservé aux titulaires d'une carte de stationnement pour personnes handicapées

Nom en anglais Disabled badge holders only

Que signifie ce panneau ?

Le stationnement est réservé aux véhicules affichant une carte de stationnement pour personnes handicapées.

Parking is only for vehicles displaying a disabled badge.
