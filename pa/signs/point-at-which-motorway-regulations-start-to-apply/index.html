ਅੰਗਰੇਜ਼ੀ ਨਾਮ Point at which motorway regulations start to apply

ਇਸ ਚਿੰਨ੍ਹ ਦਾ ਕੀ ਮਤਲਬ ਹੈ?

ਇਸ ਥਾਂ ਤੋਂ ਮੋਟਰਵੇਅ ਨਿਯਮ ਲਾਗੂ ਹਨ।

Motorway regulations apply from this point.
